## 📚 10 Lab Experiments Included (Complete Java Manual)

1. **Experiment 01 — Operators, Arithmetic Promotion, Method Calling**
   - Classes: `ArithmeticOperator.java`, `Driver.java`
   - Covers: Static methods (`add`, `sub`, `multi`), instance methods (`div`, `modulus`), arithmetic promotion rules, and method calling (`printName`) with parameter passing.
2. **Experiment 02 — String and Math Classes**
   - Classes: `StringProgram.java`, `mathprogram.java`
   - Covers: String equality (`equalsIgnoreCase`, `equals`), concatenation, substring, and Math operations (`max`, `min`, `sqrt`, `cbrt`, `pow`, `log`, `log10`).
3. **Experiment 03 — Function Overloading and Constructors**
   - Classes: `areaMethodOverloading.java`, `areaConstructor.java`
   - Covers: Method overloading (area of circle, square, rectangle), default constructors, and parameterized constructors.
4. **Experiment 04 — Dealing with Arrays**
   - Class: `ArrayProgram.java`
   - Covers: Dynamic array creation with `Scanner`, forward traversal, and array reversal.
5. **Experiment 05 — Advanced String and Math Methods**
   - Classes: `StringProgram.java`, `mathprogram.java`
   - Covers: `charAt`, `length`, `replace`, `contains`, `toUpperCase`, `toLowerCase`, `trim`, `round`, `signum`, trigonometric (`sin`, `cos`, `tan`, `sinh`, `cosh`, `tanh`), and degree/radian conversion.
6. **Experiment 06 — Inheritance and Polymorphism**
   - Classes: `InheritanceDemo.java`, `Inheritance.java`
   - Covers: Single-level & multi-level inheritance (`One`, `Two`, `Three` with `super`), and runtime polymorphism / method overriding with Bank rate of interest (`Bank`, `SBI`, `ICICI`, `AXIS`).
7. **Experiment 07 — Static and Abstract Modifiers**
   - Classes: `ShapeAbstractDemo.java`, `StaticProgram.java`
   - Covers: Abstract class `Shape` with subclasses `Rect`, `Triangle`, `Circle`, `Ellipse`, plus static variable and static initializer block.
8. **Experiment 08 — Interfaces and Final Modifier**
   - Classes: `FinalProgram.java`, `InterfaceProgram.java`
   - Covers: Final class, final method, final variable, and pure abstract Interface implementation for shapes.
9. **Experiment 09 — Exception Handling**
   - Class: `ExceptionHandling.java`
   - Covers: `try`, `catch`, `finally` handling `ArithmeticException` (division by zero) and `InputMismatchException`.
10. **Experiment 10 — Simple Package Creation and Access**
    - Class: `Welcome.java` (`package FirstPackage;`)
    - Covers: Package declaration, directory structure generation via `javac -d . Welcome.java`, and execution using fully qualified name `java FirstPackage.Welcome`.

## 🚀 Key Features

- **Java Syntax Highlighter**: Client-side regex engine coloring Java keywords, classes, types, numbers, strings, and directives in an IDE-style container.
- **Fast Filtering & Search**: Instant filter chips (*All*, *OOP Concepts*, *Core & Arrays*, *Strings & Math*, *Exceptions & Packages*) and search bar (shortcut: `/` or `Ctrl+K`).
- **Single-Click Copy & Download**: Prominent **COPY CODE** button (shortcut: `C`) with clipboard fallback and **Download .java** file support.
- **Verified STDOUT Outputs**: Collapsible terminal box displaying exact manual verification outputs.
- **Full Responsiveness & Accessibility**: Tested for desktop, tablet (900px), and mobile (600px), with `@media (prefers-reduced-motion: reduce)` support.
